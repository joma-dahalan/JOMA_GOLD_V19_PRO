# JOMA GOLD — Market Studio V17

## ما الذي أُضيف؟

فتح شاشة **◈ Studio** من شريط الأدوات (أو الاختصار Ctrl+K)، وإغلاقها عبر زر × أو Escape.

- **Overview**: إحصاءات EMA21/EMA55/RSI14/ATR14 من شموع الوسيط، وأزرار تفعيل ثمانية أدوات تحليل.
- **Footprint**: تجميع تدفقات الصفقات **المسجلة فعليًا** إلى مستويات أسعار وشموع؛ 3 أوضاع Classic / Delta / Volume، وتغيير ارتفاع الصف السعري بين $0.50 و$5، وعرض POC ومجموع التداول المسجل لكل شمعة. رسم اختياري على الشارت عند التقريب. قد تكون البيانات فارغة في بداية التشغيل.
- **Depth**: مستويات آخر snapshot محفوظ للدفتر + إحصاءات bid/ask وأكبر التجميعات الحديثة، مع إخفاء العمق عند انقضاء 30 ثانية.
- **Levels**: قائمة مناطق السيولة الطازجة، وأداة **Price level watch** المحلية لرصد عبور السعر أثناء فتح الصفحة (لا ترسل إشعارات بعد إغلاق المتصفح).
- **Layouts**: 3 تخطيطات جاهزة، مع حفظ واستعادة وحذف حتى 8 تخطيطات باستخدام localStorage في نفس المتصفح.
- **مؤشر Tick Density**: كثافة تقديرية باستخدام **tick volume** لشمعات الوسيط، مع POC ومنطقة القيمة.
- **مؤشر EMA/ATR Ribbon**: خطوط EMA السريع والبطيء ونطاق ATR؛ أرقام وصفية لا تتنبأ بالسوق.

كل إضافة تمت داخل هيكل مشروعك الحالي (FastAPI / Lightweight Charts / مكتبة المؤشرات)، ولم نستبدل واجهة مشروعك أو محرك البيانات.

## الفرق بين موقع indtrade ونسخة JOMA

دليل الموقع الرسمي يعرض خمسة مؤشرات بارزة: Pulse V2 وXRay وInside Levels وWhales Map وPrint Pro، ويذكر عرض الاشتراك وجود 11 مؤشرًا مدفوعًا. هذا المشروع يحتوي على **بدائل وظيفية مستقلة** للأغراض البحثية الخمسة، **وليس نسخة من مؤشرات الموقع أو الخوارزميات المدفوعة، وليس تكاملًا رسميًا معه**.

| مرجع الوظيفة على الموقع | الموجود في JOMA Studio | طبيعة البيانات | أهم قيد |
|---|---|---|---|
| Pulse V2 | Tick Density + EMA/ATR Ribbon | OHLC وtick volume للوسيط | ليس نفس Pulse ولا كودًا مستخرجًا منه |
| XRay | Heatmap + Levels | دفتر أوامر مزودين مرتبطين بالذهب | **ليست** liquidations حقيقية |
| Inside Levels | Volume Profile / Value Area | tick volume لشمعات الوسيط | تقدير مكاني للحجم وليس حجم تداول مركزي |
| Whales Map | Large Prints + Depth | تدفق صفقات مزودين عامين | التجميعات ليست صفقات حيتان موثقة |
| Print Pro | Recorded-flow Footprint | تدفقات صفقات عامة مسجلة | ليس Footprint موحدًا لجميع منصات الذهب |

بقية المنتجات الستة في باقة الموقع **لم تُنسخ**؛ بعض وظائف تحليل الاتجاه والبنية السعرية متاحة في مكتبة المشروع الأصلية (31 مؤشرًا متاحًا بعد الإضافات الجديدة).

## تشغيل حقيقي

### Windows
1. فك ضغط الملف في مجلد محلي.
2. شغّل `install.bat` عند أول مرة.
3. انسخ `config.local.json.example` إلى `config.local.json` وأضف بيانات الوسيط **الخاصة بك**. لا تشارك هذا الملف.
4. شغّل `doctor.bat` لمعرفة حالة المصادر.
5. شغّل `start.bat` وافتح `http://127.0.0.1:8080`.

### Linux/macOS
```bash
python -m pip install -r requirements.txt
cp config.local.json.example config.local.json
python doctor.py
./start.sh
```

**مهم:** لا يوجد تاريخ مصطنع أو feed تجريبي ضمن ملفات النسخة. يجب ضبط مصدر شموع OANDA أو MT5 حتى يظهر الشارت، وتحتاج بيانات المزودين العامين وتسجيلًا مستمرًا لتغذية السيولة وFootprint. بيانات البورصات المرتبطة بالذهب ليست بيانات spot XAUUSD شاملة. لا ضمان لاتصال المصادر الخارجية من كل بلد أو شبكة. الإعدادات العامة متاحة في `config.json`.

## جودة البيانات
- لا تظهر خلايا Footprint غير المسجلة؛ لا تُملأ الفترات الفارغة اصطناعيًا.
- يُطابق الخادم الصفقات بفترات شموع الوسيط التي يرسلها العميل. تُهمل الصفقات الواقعة خارج فترات الشموع المعروفة (مثلاً فجوات الإغلاق).
- إذا تجاوز الاستعلام 60,000 صف محفوظ، يظهر تحذير بأن النتائج ربما تكون ناقصة.
- يختفي Depth Ladder إذا تجاوز عمر snapshot ثلاثين ثانية.
- في حال تعذّر تحميل Footprint، تُزال آخر نتيجة من العرض بدل عرضها على أنها جديدة.
- التخطيطات وتنبيهات الأسعار محلية في نفس المتصفح ولا تعمل حين تكون الصفحة مغلقة.

```bash
python tests/run_all.py
```
